Core Research Question
Can an evolving knowledge graph help AI agents remember the most up-to-date information across long conversations?



Executive Summary


Large language models can reason over information placed inside their context window, but persistent long-term interaction introduces a harder problem: facts change. A user can move to a new city, revise a plan, replace a device, change a preference, or correct an earlier statement. Conventional vector-memory systems may retrieve both the stale and current versions because both remain semantically relevant.
Amnesia is proposed as a long-term memory agent that converts conversational events into an evolving knowledge graph. Each memory is represented as structured evidence with entities, relations, time, provenance, and status. When new information arrives, a reconciliation layer determines whether it duplicates, supports, updates, contradicts, or supersedes an existing memory. Retrieval then combines semantic relevance, graph structure, temporal validity, and reconciliation state before supplying context to an LLM.
The academic scope deliberately focuses on the research kernel rather than a complete commercial memory platform. The project will compare conventional vector retrieval, graph-only retrieval, and the proposed contradiction-aware temporal approach using multi-session conversations that contain stable facts, updates, corrections, temporary states, and supersession. Evaluation will include retrieval quality, contradiction classification, answer accuracy, stale-memory error rate, and false invalidation rate.
Review 1 Status
This report defines the problem, research gap, novelty, dataset protocol, architecture, baselines, and evaluation plan.


1. Problem Statement


Current LLM-based assistants are increasingly expected to operate across long-running conversations and repeated user interactions. Because the entire interaction history cannot always remain in the active context window, external memory systems commonly store conversation chunks or extracted facts and retrieve them when a future query appears relevant.
The core limitation is that semantic relevance does not guarantee temporal correctness. Older and newer memories about the same subject can both be highly similar to a query even when only one remains valid. This creates stale-memory failures in which an agent recalls a fact that was once correct but has since been updated, corrected, cancelled, or superseded.
Example
Session 1: “I live in Hyderabad.”  →  Session 8: “I moved to Chennai.”  →  Query: “Where do I live now?”
A similarity-only memory store may retrieve both statements. Amnesia should preserve both as history while marking Chennai as the currently valid belief.


The project therefore studies long-term memory as an evolving state-management problem rather than only a storage-and-retrieval problem.
2. Objectives


Design a structured memory representation that captures entities, relations, temporal validity, provenance, confidence, and memory state.
Extract candidate facts and relations from multi-session natural-language conversations.
Classify the relationship between incoming and existing memories as duplicate, supporting, updating, contradictory, superseding, or unrelated.
Maintain an evolving knowledge graph in which outdated facts remain historically traceable but are not treated as current state.
Develop a hybrid retrieval method that combines semantic similarity, graph relevance, temporal validity, and reconciliation status.
Optionally use a memory-necessity gate to avoid unnecessary retrieval for queries that do not depend on long-term personal or session-specific information.
Evaluate the proposed method against conventional baselines using retrieval, classification, temporal consistency, answer-quality, and efficiency metrics.

The literature changes the novelty claim of this project in an important way: temporal knowledge graphs themselves are not new. Accordingly, Amnesia does not claim novelty merely from using a graph or timestamps. The project contribution is instead centered on a specific hybrid reconciliation and evaluation strategy for evolving conversational facts.
4. Research Gap


Existing memory approaches demonstrate strong retrieval and long-context behavior, while recent temporal-graph systems already preserve fact histories. However, the practical failure that matters for a conversational agent is narrower: deciding when a new statement should change the agent’s current belief without incorrectly deleting or invalidating unrelated facts.
Similarity-based retrieval can surface mutually inconsistent memories because semantic closeness is agnostic to which fact is current.
Knowledge-graph retrieval can organize relationships but does not automatically guarantee correct temporal updates.
Temporal memory requires a reliable reconciliation decision: additive information, correction, contradiction, and supersession must be distinguished.
Aggressive invalidation can create a second failure mode: a still-valid fact may be retired because a model incorrectly judges it as contradictory.
Many evaluations emphasize retrieval accuracy; a project centered on evolving user state should explicitly measure stale-memory errors and false invalidations.
Gap → Novelty
Research gap: long-term memory systems need safer, explicit reasoning about how new facts relate to existing facts.
Proposed novelty: a relation-aware reconciliation layer plus hybrid temporal retrieval, evaluated specifically on evolving multi-session facts and stale-memory failure modes.


5. Proposed Novelty and Contributions


The project proposes the following contribution set. The novelty is a hybrid method and experimental framing, not the generic use of an LLM or knowledge graph.
Contribution
Description
1. Relation-aware reconciliation
For each new assertion, jointly consider subject, relation, object, time, and candidate memories before deciding duplicate / support / update / contradict / supersede / unrelated.
2. Explicit memory lifecycle
Keep historical facts but attach current, superseded, invalid, or unresolved state rather than overwriting the past or treating all memories equally.
3. Hybrid retrieval score
Combine semantic relevance with graph relevance, temporal validity, confidence, and contradiction penalties.
4. Evolving-memory benchmark slice
Construct controlled multi-session scenarios containing corrections, renames, plan changes, temporary states, preference shifts, and ownership/location updates.
5. Failure-oriented metrics
Measure stale-memory error rate and false invalidation rate in addition to conventional retrieval and QA metrics.
6. Memory necessity gate (optional)
Classify whether a query needs long-term memory before retrieval, reducing irrelevant context, latency, and token cost.

7. Proposed Architecture



Figure 1. Proposed Amnesia research architecture.
7.1 Memory Extraction
An LLM or structured extraction model converts each conversation event into candidate assertions such as (subject, relation, object), with source evidence, timestamp, confidence, and optional validity hints.
7.2 Entity and Relation Resolution
New entities and relations are matched against the existing graph to reduce duplicates and preserve identity across paraphrases, renamed objects, and repeated mentions.
7.3 Evolving Temporal Knowledge Graph
The graph stores entities as nodes and factual assertions as time-aware edges. Historical facts are preserved even after they stop being current. The model therefore represents both present state and how that state evolved.
7.4 Reconciliation Engine
For each incoming assertion, candidate existing memories are compared and labeled as SAME, SUPPORTS, UPDATES, CONTRADICTS, SUPERSEDES, or UNRELATED. Structural constraints can restrict invalidation to semantically compatible subject-relation scopes.
7.5 Hybrid Retrieval
Candidate memories are ranked using semantic similarity, graph relevance, temporal validity, confidence, and penalties for superseded or contradicted state. The goal is to deliver concise current context rather than a pile of loosely similar memories.
7.6 Memory Necessity Gate
Before retrieval, an optional classifier predicts whether the user query actually depends on long-term memory. Generic questions can bypass memory, while personal or cross-session questions activate retrieval.
A candidate retrieval score can be expressed as:
Score(m, q) = α·Semantic + β·Graph + γ·Temporal + δ·Confidence − ε·StalenessPenalty

Project Positioning
Amnesia is not “a chatbot with memory.” The research prototype tests whether an AI agent can maintain an evolving representation of what is currently true while retaining the evidence and history of what used to be true.
